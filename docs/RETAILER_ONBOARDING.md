# Retailer onboarding

1. Confirm the business identity, website ownership and genuine-product commitment.
2. Create the retailer profile and locations; verification remains separate from plan or sponsorship.
3. Start with the CSV template and validate every row before import.
4. Confirm HTTPS product destinations, stock semantics, shipping, free-delivery threshold and collection support.
5. Run a baseline import before enabling stock alerts.
6. Review storefront copy, opening hours, delivery details and event information.
7. Enable only the plan entitlements agreed with the retailer. Organic discovery is available independently of sponsored placement.

Shopify, WooCommerce and feed adapters remain disabled until legitimate endpoints and server-side credentials exist.
