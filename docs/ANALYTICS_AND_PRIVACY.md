# Analytics and privacy

Outbound purchase actions accept HTTPS destinations only. FateDrop records retailer, offer, placement, timestamp and a random anonymous installation session identifier. It does not need a name, email or precise location for click measurement.

The development retailer dashboard reports recorded outbound clicks. Metrics without evidence are shown as unavailable, not generated. Storefront views, impressions, detail views, CTR, FateFind matches, wishlist saves and event engagement require a production event pipeline and consent review before activation.

Precise Local Radar coordinates remain device-side and are not published. Postcode is available as a manual alternative.
